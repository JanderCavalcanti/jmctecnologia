# JMC Tecnologia e Consultoria

Landing page institucional de www.jmctecnologia.com.br. Site estático (HTML, CSS e JS puros, sem build), pronto para o GitHub Pages.

- `index.html`: conteúdo da página
- `assets/css/styles.css`: estilos; as cores da marca ficam nas variáveis do topo (`--primary`, `--accent`)
- `assets/img/`: coloque aqui o logotipo oficial (`logo.png`) e troque o bloco `.brand` no `index.html`
- `CNAME`: domínio próprio usado pelo GitHub Pages

Para visualizar localmente, abra o `index.html` no navegador.
